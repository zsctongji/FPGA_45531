## 第一天先做

1. 登记实际 PCB、摄像头、红外、温湿度、蜂鸣器及转接件型号、照片和到货状态。采购建议不能替代实物型号。
2. 对照实际原理图写接线表：接口/信号/电压/FPGA 管脚。未核对的引脚不填猜测值。
3. 与 C 固定 I2C、GPIO、定时器底层适配方式；传感器工作不必等待完整实时 AI。
4. 使用厂家资料和对应原厂库，先完成一组真实温湿度读数和一次真实红外完整帧。

## 模块任务

- 温湿度：CRC、单位换算、超时、重试，连续不少于 100 次记录。
- 红外：按实际型号完成 EEPROM/校准/坏点及子帧处理；如为 MLX90640，交付每帧 768 个温度值。先保证完整、正确、带时间和状态，再提高刷新率。
- 滤波和时间：合理范围/突变检测、异常不写历史、毫秒时间、断线和过期标志。
- 空间关系：与 A 固定相机和红外安装，检查画面上下左右一致，至少做左/中/右热目标对照；显示先用独立热图区域。
- 报警：按实际蜂鸣器规格选择电平或 PWM，驱动 LED/蜂鸣器，验证触发、保持、解除和重新布防。
- 板端网络：从厂家 GE 例程起步，逐步把真实事件/缩略图送至 A 的 PC；C 协助 SoC/缓冲连接。不能用串口输出替代网络扩展验收。
- 文档：完成本人章节，汇总三人的报告/PPT排版；各人的技术内容和原始证据仍由本人提供。

## 依赖与交付

C 提供底层访问和统一时间，A 提供帧号、缩略图及 PC 报文格式。B 交付驱动源码、库版本、接线表、温度图/环境 CSV、传感器异常测试、报警录像、板端网络及本人文档。

错误数据不得变成“0℃”“无人”或“正常”；热图必须来自真实阵列和规定温度换算，不能用固定图或随机图作为验收结果。

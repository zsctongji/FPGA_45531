## 软件接入边界

1. 合入 team_work/02_sensors_alarm/include 与 src；复用团队当前 c3_hal.h、cooperation_v1.h。upstream_snapshot 仅供离线对照，不要作为第二套接口混入固件。
2. 当前本地对照 ABI 为 0x00010000；COOP_SAMPLE_VALID=7。发布有效样本时同时要求 get 返回 COOP_OK、valid_flags=7、error_bits=0，并检查年龄。最终仍须与 C 的当前接口比对。
3. 温湿度地址先核验 0x45，再核验 0x44；热成像地址候选 0x33。HAL 参数用 7 位地址。共用总线由单个任务/锁串行调度。
4. MLX90640 还需接入实际服务：读取本器件 EEPROM → 官方 ExtractParameters → 获取新子页 → 官方温度换算/坏点处理策略 → b_thermal_push → b_thermal_get。当前适配层和组装器不能替代这条采集链。
5. 两页必须不同、模式一致；现有快照的热图子页配对与样本年龄上限 500ms，环境样本年龄上限 2000ms。刷新率和调度若不满足，需团队一起调整接口与测试，不能悄悄复用旧样本。
6. 现有报警输出为 250ms 开、750ms 关，LED 在活动时保持亮；max_on_ms 由调用者传入。C 负责跌倒/融合判据。服务调度周期影响实物时序，需一起测量。
7. c3_hal_t 回调缺失/ENOTSUP 必须报告；不得用空后端或假数据作为板上通过。GPIO 写失败时物理状态未知，要实测并记录。
8. 本次没有改现有 C 源码，没有运行 FPGA 综合、RISC-V 编译、烧录、真实总线或网络测试。已核对远程公共时间接口与 C2/APB v2.2 更新；软件 ABI v1 不随之改号。

# 传感器标量预处理模块

`sensor_smooth.v` 对已经完成校准、换算的单通道采样执行范围检查、突变检查和最近 4 次有效采样滑动平均。可实例化多次，分别用于环境温度、湿度或红外像素数据。

它还没有连接 I2C，也没有实现 MLX90640 EEPROM 校准、整幅热图拼帧或三路融合。

默认输入为有符号 16 位整数。若单位为 0.01 摄氏度，允许范围为 -40 到 125 摄氏度，相邻接受采样的变化不得大于 20 摄氏度。湿度实例必须重新设置范围和突变参数。超出阈值的采样不会进入平均窗口；真实突变也可能被这一保守规则剔除，必须结合采样周期和实际数据调整 MAX_STEP，不能直接作为安全报警判据。

复位为同步高有效。采样有效时每拍可接收一个值，无反压。接受的样本在该时钟边沿后令 out_valid=1，mean_data 为含本次采样的平均值。拒绝采样令 rejected=1，out_valid=0，保留历史窗口。无采样时两标志清零。前 1 到 3 次采样按实际数量平均，满 4 次后移动窗口；有符号除法向零截断。

`tb_sensor_smooth.sv` 检查已知序列、窗口滚动、负温度、边界外值、突变、空拍、连续采样与复位。实际测试结果见 logs/selftest.json 和本模块仿真日志。

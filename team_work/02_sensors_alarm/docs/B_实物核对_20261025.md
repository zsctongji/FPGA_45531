## 模块侧电气核对

### SHT30 / SEN0330

- 官网工作电压 2.15~5.5V；实际接线必须先满足主板 IO 电压。
- 官方 SEN0330 原理图显示 SDA、SCL 各经 10kΩ 上拉至 VDD；因此给模块 5V 时不能把其信号直接接到未确认可容忍 5V 的 FPGA。
- ADDR 通过板上网络选择；DFRobot 参考代码说明 ADR=VDD 对应 0x45，ADR=GND 对应 0x44，默认 0x45。现有 B 驱动允许这两个地址，没有把地址固定为 0x44。
- INT 是告警输出，RST 是复位输入；基本温湿度采样不需要把 INT 纳入数据接口。RST 的保持条件和可选复位后端按传感器手册落实，不随意拉低，也不据照片虚构额外管脚。
- 本次官方 PDF 的 SKU 为 SEN0330，标题栏却写 SHT31；作为此 SKU 共用转接板参考，芯片型号以实物 SHT30 与对应手册为准。

### Waveshare 热成像模块

- 新增购买页标明 MLX90640-D55、55°×35°；按用户提供的购买型号继续适配。对应官方页面支持模块 VCC=3.3V/5V、板载电平转换。实际 I2C 和 EEPROM 尚未核验。
- 配套原理图：模块内部 3V3 稳压、两路 NDC7002N 电平转换；外侧 SDA_EXT / SCL_EXT 各由 4.7kΩ 拉至 VCC。
- 因而“模块支持 5V”不能用来证明“当前 FPGA 可直连 5V”。模块侧选用电压必须与确认后的接口电平兼容；必要的板级转换由原理图决定。
- 照片/厂家连接器定义按 SCL、SDA、GND、VCC 信号匹配；不按线色或仅凭插头形状确定方向。

### Seeed Buzzer v1.3

- 厂家 Grove-Buzzer 系列资料标注 3.3V/5V，数字 HIGH 可发声，也支持 PWM 生成音调。
- 按逻辑 GPIO 通道 1 继续使用现有报警输出服务；物理 SIG 极性/电平留给 C 后端核对。
- NC 不接数据线；GND、VCC、SIG 按实物丝印定位。这个四针插口不能当成热成像模块的四针 I2C 插口使用。

## 对 B / C3 的交接结论

1. 主板与扩展板原理图已收到；完整核对及候选球位见 B_厂家资料核对_20261025.md、待核对接线表.csv。候选 SCL=J28.37/B3，SDA=J28.39/C3，蜂鸣器=J28.38/B5，尚待当前工程约束、电源及实物核验，不能直接视为接线定稿。
2. SHT30 首次优先核验 0x45，再核验 0x44，通过有效响应和 CRC 后记录实际地址。
3. 热成像按购买页 MLX90640-D55、32×24、55°×35°继续适配；实际校准参数、采样与视场没有测量。
4. 绿色转接板的 J26→J28 同号直通已有原理图依据；实物插接方向、电源和连续性仍需核验，子卡 PCB 版本不能代替主板版本。
5. 报警接口继续沿用逻辑 GPIO 0/1；本次只改核对文档，不改变已有软件逻辑，不重复运行合成测试。
6. 主板资料标称 Flash GD25LQ64/8MiB、DDR MT41J128M16JT-125/256MiB。新照片中 U14 第二行更像 `25Q64JWSIQ`，当前按 Winbond W25Q64JW 系列、1.8V 方向记录；U12 为 `3HK77 / D9PTK`，D9PTK 对应 MT41K128M16JT-125:K。主板精确修订号、U14 完整订货后缀和实际供电仍需闭环。

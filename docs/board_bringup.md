## 需要先确认的实际设备

厂家已从包装确认是炫览科技，用户确认免费申请板及 Ti60F225。V4 原理图、完整例程、摄像头 v7 和 TinyML 已取得；仍须核对实物 PCB 版本及摄像头模组。题三还需要红外温度阵列与环境温湿度传感器，需确认是否已有和各自型号。

厂家资料应至少包括：

- 核心板和底板原理图、管脚和 IO 电压、时钟频率、电源与下载接口说明。
- 对应此板版本的 Efinity 工程、Interface Designer 配置、SDC 时序约束。
- MIPI 摄像头初始化表与参考采集工程、RAW 格式和 Bayer 排列。
- DDR 读写例程、HDMI/LCD 例程、Sapphire RISC-V SoC 例程及对应 SDK/工具版本。
- 红外阵列与温湿度传感器电源/IO 电平、I2C 地址、数据手册与校准流程。

不同 Ti60 板卡不能混用管脚。当前工作工程保留厂家外围配置，摄像头预处理副本的外围文件哈希与原例程相同；这些配置尚未与用户实物核验。没有添加猜测管脚或传感器寄存器表。

## 获得资料后的实际顺序

1. 确认原厂供电、下载口和设备枚举；先让对应板卡的 LED/串口最小例程运行。
2. 安装/验证与厂家例程一致的 Efinity、许可证与 RISC-V 工具链，编译原始例程并保留日志。
3. 跑 HDMI 彩条；再跑 MIPI 摄像头直通。采集 1280×720 帧和实际帧时间间隔，确认稳定采集。
4. 接入已验证预处理模块，注意 Sobel 输出裁剪为 (W-2)×(H-2)，显示端需补边或调整有效区域；不要仍按原图帧尺寸写 DDR。
5. 逐个调通 I2C 设备。红外阵列先验证 EEPROM、双子帧、校准和目标温度；环境传感器核对 CRC/换算，再加入滑动平均与异常过滤。
6. 三路数据标记同源毫秒时间戳，用帧级/热图级缓冲实现对齐，再叠加视频、热力图、环境数据。
7. 部署轻量视觉模型到 Ti60 内 RISC-V/FPGA 系统，用保留的真实测试集衡量人体检测、运动分析和融合结果。
8. 集成报警及至少两项拓展；测量帧率、完整延迟、资源、识别效果、功耗和连续运行稳定性，录制演示并填写提交材料。

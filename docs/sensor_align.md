# 视频帧与环境采样时间戳对齐基础模块

文件：`rtl/sensor_frame_align.v`。测试：`sim/tb_sensor_frame_align.sv`。

该模块将一个视频帧时间戳与最新接收的一份温湿度采样记录关联，作为赛题三采集链路的基础积木。它尚未接入实际摄像头、传感器或开发板，也没有实现三路设备同步、多模态融合或 AI 推理。

## 输入与时间基准

所有输入必须已经同步到同一个 `clk` 时钟域。`rst_n` 为低有效异步复位，复位清除已见采样标志和全部输出；实际板级设计还需保证复位解除符合时序要求。

`sample_valid` 为 1 时，在该时钟上升沿保存 `sample_timestamp_ms`、`sample_temp`、`sample_humidity`。温度、湿度为原样传递的 16 位无符号数据；小数比例与传感器换算需要在具体型号确定后由适配模块定义，当前没有宣称传感器驱动已经完成。

`frame_valid` 为 1 时，在该上升沿处理 `frame_timestamp_ms`。视频时间戳通常应取帧采集开始时刻；上游必须统一定义采样时间戳代表的实际采样时刻，不能将处理完成时刻与采集开始时刻混用。

两个时间戳都是 **同一个起点、同一个时间基准的 32 位无符号毫秒计数**，计数器自然回绕。模块不产生时间戳，不校正时钟偏差，不执行跨时钟域同步。输入 valid 可连续多个周期为 1；每个周期视为一条新的记录。

## 配对规则

`MAX_AGE_MS` 默认是 1000 毫秒，允许范围为 `0 <= MAX_AGE_MS < 2^31`。

每个视频帧选择最近一次**接收**的采样记录。收到采样更新即覆盖原记录，不按时间戳排序，也不保留历史采样。若 `sample_valid` 与 `frame_valid` 同一周期为 1，当前周期的新采样优先于旧记录；新采样在未来时，也不会回退使用旧记录。

按 32 位无符号模运算计算：

```text
age = (frame_timestamp_ms - selected_sample_timestamp_ms) mod 2^32
有效配对 = 已观察到采样 && age < 2^31 && age <= MAX_AGE_MS
```

判断成立时 `pair_valid=1`、`stale=0`。没有采样、采样在帧的未来、采样超过允许年龄，或者时差恰好为 `2^31` 的歧义情况，都输出 `pair_valid=0`、`stale=1`。

半范围判断要求所有需要比较的实际时差小于 `2^31` 毫秒，约 24.86 天。32 位时间戳无法区分任意多个回绕；长时间停采后必须在上游重新开始会话并复位该模块，或提供额外的有效性管理，不能让旧记录无限期存活。

示例：

|采样时间戳|帧时间戳|年龄|当 `MAX_AGE_MS=100` 时|
|---|---|---|---|
|1000|1000|0|有效|
|1000|1100|100|有效，包含边界|
|1000|1101|101|过期，无效|
|1000|999|`0xffffffff`|采样在未来，无效|
|`0xfffffff0`|`0x00000014`|36|跨回绕有效|
|`0x00000014`|`0xfffffff0`|`0xffffffdc`|跨回绕未来采样，无效|

## 输出契约

输入在时钟上升沿采纳，输出寄存器在该沿后更新。下游同步逻辑在下一上升沿读取这些结果。

- `pair_valid`：当前输出快照是有效配对；下游必须以此为消费条件。
- `stale`：本周期存在待配对帧但无法配对。它合并了未收到采样、未来采样和过期等原因，不表示只有“过期”这一种原因。
- `pair_frame_timestamp_ms`：当前帧时间戳。
- `pair_sample_timestamp_ms`、`pair_temp`、`pair_humidity`：当前帧选择的最新接收采样快照。
- `pair_age_ms`：该快照与帧的 32 位模时差。

若尚未接收任何采样，输出采样快照和年龄为零，但 `pair_valid` 仍为 0；零时间戳或零数据不会自动视为已有采样。只有实际 `sample_valid` 更新后，时间戳与数据全零的记录才能成为有效采样。

有采样但无法配对时保留所选采样快照及模时差，供诊断使用；这些数据不能按有效配对处理。没有 `frame_valid` 的周期，`pair_valid` 和 `stale` 清零，输出数据快照保持不变。复位优先于所有 valid 输入。

## 自检覆盖与执行记录

测试参数为 `MAX_AGE_MS=100`，包含未观察采样、年龄为零、界限前一毫秒、界限值、过期一毫秒、未来一毫秒、同周期新采样优先、禁止退回旧采样、正常回绕、回绕后的界限、未来跨回绕、恰好半范围、零数据的有效采样、复位覆盖 valid、复位清除历史、非时钟沿异步复位立即清除非零快照，以及固定种子的 2000 个随机周期。参考模型使用 64 位数学取模，逐周期比较全部输出和空闲保持行为；任何不匹配均 `$fatal`。

全部自检已使用 Vivado XSim 2018.3 在正常运行环境中实际通过：2026 次检查、518 次有效配对、502 次拒绝、17 次复位，包含 2000 个固定种子随机周期。受限环境曾出现 DLL 启动错误，原始失败日志保留；没有修改 Vivado 安装或系统设置。成功证据见 logs/tb_sensor_frame_align.run.log 与 logs/selftest_xsim.json。

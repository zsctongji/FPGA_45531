## 你接下来按顺序做

1. 把 B_给AC的交接说明_20261027.md 发给 A/C，请他们先确认工程版本、引脚和 C3 后端。
2. 准备开发板、绿色转接板、传感器、蜂鸣器、万用表和可靠的连接线。SHT30 排针孔若仍未焊接，请熟悉焊接的同学协助安装排针或使用匹配连接器，避免把松动杜邦线硬塞进孔中。
3. 断电核对 J7—J26 对接方向及 J28 的 1/2、39/40 标记，按现有教程连接；先接转接板，再分别验证 SHT30、MLX90640，最后接蜂鸣器。
4. 由熟悉板卡的同学测量模块电源和 IO 电压，确认 FPGA 初始输出状态、上拉和供电预算。接线图中的 3.3V 是候选电源，测量通过后才能填为已确认。
5. 用 A/C 提供的当前固件开展逐项测试，把原始日志、实物照片和工程哈希填到 B_上板测试记录_20261027.md。
6. 单模块通过后再同时接入，最后与摄像头、融合判据、网络接收端联调。

## 什么时候算 B 完成

- 硬件信息、接线表和模块型号均有证据；未闭环项目明确交给具体负责人。
- SHT30、MLX90640 与蜂鸣器的真实测试达到团队约定指标。
- B 的代码已接入团队当前接口，A/C 能复现采样、报警与故障恢复。
- 原始日志、照片、固件版本及测试记录已归档。

拍完两颗芯片能够推进身份核对；B 的最终验收仍包含真实采样与输出验证。摄像头采集、推理、完整跌倒判据和网络功能需要团队共同完成。

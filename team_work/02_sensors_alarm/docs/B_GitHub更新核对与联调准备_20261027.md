## 下载器是否需要另买

用户提供的厂家《TI60F225I3-V4 DEMO板软硬件设计说明-260924》第 2.7.1 节（PDF 第 14 页）明确板载 FT4232HL，可通过一根支持数据的 Type-C USB 线实现供电、下载与 UART。当前优先验证板载方案，暂不采购外置 JTAG 下载器或 USB 转串口。

需要实物和 Windows 枚举共同确认板载 USB 下载部分完好、所接接口正确。若仅亮电源灯但没有 USB 枚举，先检查线材是否支持数据、USB 端口和配套驱动；再由团队判断外置方案。J7/J26/J28 是本次传感器转接路径，不能当作电脑 USB 下载接口。

ST-Link/J-Link 不是本项目默认 FPGA 下载方案。是否需要某种外置探针，取决于 C 当前调试连接与厂家支持配置；不要只因以前用过 STM32 就先购买。

## 实物器材

| 器材 | 优先级 | 用途/检查 |
|---|---|---|
| 支持数据的 USB-A 转 Type-C 或 Type-C 转 Type-C 线 | 首次上板必备 | 连电脑与主板厂家规定的 USB 下载/供电口；按实物接口和原厂说明核对 |
| 主板、配套转接板和传感器 | 必备 | Ti60F225 主板、EL_001_REV2.0、SHT30、MLX90640-D55、有源蜂鸣器 |
| 可靠的杜邦线/匹配连接线、面包板、排针 | 必备 | 按模块端和 J28 选公母端；SHT30 孔位未焊接时请熟悉焊接者安装排针，不靠松动接触 |
| 万用表 | 强烈建议首次接线就有 | 断电确认共地/导通/短路，上电测真实供电；不在密脚芯片脚间盲探 |
| 网线及可用以太网口/USB 网卡 | 网络联调时必备 | 电脑到板卡；地址配置按 A 的接收端说明 |
| HDMI 线和显示器 | 摄像头/显示联调时需要 | 核对主板输出口与当前工程，B 的单传感器测试可先用串口 |
| 示波器或支持相应 IO 电平的逻辑分析仪 | 排查总线时选配 | 测 I2C 波形、脉冲和时延；可先借实验室设备，不是第一次 USB 枚举的前置条件 |

供电按厂家和实物确认的方式，第一次先裸板、随后逐个加模块，核对外设电流预算。资料给出 USB 供电方案，不据此擅自增加第二路外部电源或改变跳线。

## 第一次连接的检查顺序

1. 先不接传感器，用可靠数据线连接主板指定 USB 口；打开设备管理器，记录 FTDI/JTAG/UART 设备名称、硬件 ID 与 COM 口。枚举成功不代表 FPGA 程序已正确运行。
2. 安装并验证匹配的 Efinity/驱动，在 Programmer 查看下载器及 JTAG 器件能否识别。先进行识别，不执行 Flash 擦除或持久化写入。
3. 由 A/C 提供与此板兼容的最小 LED/UART 产物、加载命令和串口设置；按其说明进行 SRAM 临时配置/固件加载，观察真实 LED 与日志。
4. 核对 FPGA 初态、模块电压和最终引脚后，断电接 SHT30，得到真实 CRC 通过读数；再分别接 MLX90640 和蜂鸣器。
5. 使用本次记录模板保存工程版本、接线照片、原始日志与错误；单模块通过后再加入摄像头/DDR/网络联调。
